Заплатка — калькулятор (сборка 07.09.2026, мобильная вёрстка v2)

Структура уже развёрнута для отдачи статикой, переименования сделаны:

  index.html         — главная: калькулятор с промо-блоком «Перейти в Заплатку»
  calculator.html    — тот же калькулятор без промо (чистая версия)
  assets/            — js/css с хэшами в именах (4 файла)
  robots.txt         — нужен, только если калькулятор живёт в корне домена
  sitemap.xml        — аналогично

Если заливаете не в корень, а в подкаталог (например /calculator/):
  - index.html и calculator.html можно переименовать как угодно — ссылки
    на assets/ относительные, работать будут;
  - robots.txt и sitemap.xml можно не заливать.

Если калькулятор станет главной страницей по адресу без имени файла —
сделайте index.html ту версию, которая нужна (по умолчанию тут главная
с промо Заплатки).

Кэширование: assets можно кэшировать навсегда (имена с хэшами меняются
при пересборке); *.html кэшировать нельзя.
